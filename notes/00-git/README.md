# Git 学习笔记

这个目录用于沉淀 Git 的核心概念、常用命令和练习记录。建议每学一个主题，都同时写一份笔记并在 `labs/git-playground` 里做一次实际操作。

## 推荐顺序

2. [02-branch-merge.md](02-branch-merge.md)
3. [03-conflict.md](03-conflict.md)

5. [05-reset-revert-restore.md](05-reset-revert-restore.md)
6. [cheatsheet.md](cheatsheet.md)

## 复习标准

- 能解释命令改变的是工作区、暂存区还是提交历史。
- 能在出错时用 `git status`、`git log`、`git diff` 判断当前位置。
- 能在不丢失重要内容的前提下撤销错误操作。
