# 04 SO(3) 与 SE(3) 参考答案

这份答案按原题号给出一版标准表述，重点补齐定义、公式和常见易错点。你可以先自己作答，再用这份对照修正。

## A. 坐标系与旋转基础

### A1. 点、向量与坐标表示

点是几何位置，向量是方向和长度。  
同一个几何对象在不同坐标系下会有不同数值表示，所以“向量/点本身”和“它在某个坐标系下的坐标”要区分开。

### A2. 主动旋转与被动变换

- 主动旋转：把几何对象本身转过去。
- 被动变换：坐标系变了，对同一个对象重新记坐标。

很多公式看起来一样，本质只是约定不同。阅读时要先确认 `R` 是“把 B 系坐标变到 A 系”，还是“把向量主动转到新方向”。

### A3. 旋转矩阵的约束

三维旋转矩阵 `R` 属于 `SO(3)`，满足：

- `R^T R = I`
- `det(R) = 1`
- `R^{-1} = R^T`

含义是：长度不变、角度不变、且不发生镜像翻转。

### A4. 基本旋转与手算

绕 `z` 轴旋转角 `theta` 的矩阵为：

```text
[ cos(theta)  -sin(theta)   0 ]
[ sin(theta)   cos(theta)   0 ]
[     0            0        1 ]
```

若 `point = [1, 0, 0]^T` 绕 `z` 轴主动旋转 `90°`，结果是：

```text
[0, 1, 0]^T
```

长度保持不变，说明旋转只改方向，不改模长。

### A5. 旋转复合与顺序

若 `R_ab` 表示把 `{B}` 中的坐标变到 `{A}`，`R_bc` 表示把 `{C}` 中的坐标变到 `{B}`，则：

```text
R_ac = R_ab R_bc
```

矩阵乘法顺序不能随便交换，因为它表示的是“先做谁、后做谁”的复合线性变换。

### A6. 相对旋转

若 `R_world_1`、`R_world_2` 分别表示姿态 1 和姿态 2 在世界系下的旋转，则从姿态 1 到姿态 2 的相对旋转可写为：

```text
R_21 = R_world_2^T R_world_1
```

等价地，也可写成“先回到世界系，再去到目标系”的组合。关键是把坐标约定写清楚。

## B. 欧拉角、轴角与四元数

### B1. 欧拉角

欧拉角是用三个角描述姿态的一种参数化。  
常见的 `ZYX` 约定一般表示 yaw、pitch、roll 的组合，但不同顺序对应不同姿态，因此顺序必须明确。

### B2. Gimbal lock

在 `ZYX` 欧拉角中，当 pitch 接近 `±90°` 时，会出现两个转轴对齐，导致参数化退化。

- 这是欧拉角参数化的奇异性
- 不是刚体真的少了自由度
- 会表现为某些角度数值突变、控制不稳定、插值困难

### B3. 轴角表示

轴角由单位轴 `u` 和转角 `theta` 构成。对应的反对称矩阵：

```text
[u]_x = [  0   -u_z  u_y
          u_z   0   -u_x
         -u_y  u_x   0  ]
```

Rodrigues 公式：

```text
R = I + sin(theta)[u]_x + (1-cos(theta))[u]_x^2
```

当 `theta = 0` 时，`R = I`。

### B4. 叉乘与反对称矩阵

若 `v = [v1, v2, v3]^T`，则：

```text
[v]_x = [  0   -v3   v2
          v3    0   -v1
         -v2   v1    0  ]
```

并且对任意 `p` 都有：

```text
[v]_x p = v x p
```

### B5. 四元数

单位四元数通常写作：

```text
q = [w, x, y, z]
```

其中实部 `w`，虚部为向量部 `[x, y, z]`。单位约束是：

```text
w^2 + x^2 + y^2 + z^2 = 1
```

不同库可能采用 `[w,x,y,z]` 或 `[x,y,z,w]`，必须看文档。

### B6. 双覆盖

`q` 和 `-q` 表示同一个旋转。  
这是因为四元数对 `SO(3)` 是双覆盖映射。比较、插值、平均时通常要先统一符号，否则会出现跳变。

### B7. 四元数乘法

设 `q1 = [w1, v1]`，`q2 = [w2, v2]`，则 Hamilton 乘积为：

```text
q1 ⊗ q2 = [w1 w2 - v1·v2,
           w1 v2 + w2 v1 + v1 x v2]
```

四元数乘法一般不可交换。  
旋转向量常写成：

```text
p' = q ⊗ [0, p] ⊗ q^{-1}
```

### B8. 表示法比较

- 旋转矩阵：无奇异，适合链式计算，但有 9 个数和约束。
- 欧拉角：最直观、最省参数，但有奇异性。
- 轴角：参数更紧凑，几何意义清楚，但在 `pi` 附近有边界问题。
- 四元数：适合插值、优化和数值计算，但有单位约束和双覆盖。

机器人里通常用旋转矩阵或四元数做计算，用欧拉角做人类读写。

## C. SE(3) 与齐次变换

### C1. SO(3) 与 SE(3)

- `SO(3)` 只表示旋转
- `SE(3)` 表示旋转 + 平移的刚体变换

三维姿态一般需要 6 自由度：3 个旋转 + 3 个平移。

### C2. 齐次变换矩阵

```text
T = [ R  t ]
    [ 0  1 ]
```

其中 `R` 是旋转矩阵，`t` 是平移向量。  
把点写成 `[x, y, z, 1]^T` 后，旋转和平移就能统一为一次矩阵乘法。  
方向向量应补 `0`，因为方向不应受平移影响。

### C3. 位姿变换手算

若 `{B}` 相对 `{A}` 绕 `z` 轴转 `90°`，且原点在 `{A}` 中位置为 `[1, 2, 0]^T`，则：

```text
T_ab = [ 0 -1  0  1 ]
       [ 1  0  0  2 ]
       [ 0  0  1  0 ]
       [ 0  0  0  1 ]
```

点 `[1, 0, 0]^T` 在 `{B}` 中变到 `{A}` 后为：

```text
[1, 3, 0]^T
```

### C4. 逆变换

若：

```text
point_a = R_ab point_b + t_ab
```

则逆变换为：

```text
T_ab^{-1} = [ R_ab^T   -R_ab^T t_ab ]
            [   0            1      ]
```

平移项不能简单写成 `-t_ab`，因为逆变换要把平移也换到逆方向的坐标系里。

### C5. 变换链与 TF

若已知 `T_world_base`、`T_base_camera` 和 `point_camera`，则：

```text
point_world = T_world_base T_base_camera point_camera
```

TF 树本质上也是一条变换链。  
矩阵相乘顺序改变，含义就变了，所以必须沿着坐标树的父子关系来乘。

### C6. 不能直接平均旋转矩阵

旋转矩阵属于流形，不是普通欧式向量空间。  
直接逐元素平均后，结果一般不再满足 `R^T R = I` 和 `det(R)=1`。

更合理的方法有：

- 四元数平均后再归一化
- 在李代数里做 `Log` / `Exp` 平均
- 用 SVD / Procrustes 投影回 `SO(3)`

## D. 李群、李代数与 exp/log

### D1. 李群直观理解

李群是“既有群运算，又能在局部看成光滑流形”的对象。  
`SO(3)` 和 `SE(3)` 都是李群，因为它们既满足群性质，又能做局部微分和指数映射。

### D2. so(3) 与 hat / vee

`so(3)` 是 `SO(3)` 在单位元附近的切空间，对应所有 3x3 反对称矩阵。

```text
omega = [wx, wy, wz]^T
[omega]_x = [  0   -wz   wy
              wz    0   -wx
             -wy   wx    0  ]
```

`hat` 把 3 维向量变成反对称矩阵，`vee` 反过来。  
它们描述的是旋转的局部线性近似。

### D3. SO(3) 指数映射

旋转向量 `rotation_vector = theta * u` 中：

- `u` 是旋转轴方向
- `theta` 是旋转角

指数映射把它变成旋转矩阵。小角度时：

```text
R ≈ I + [omega]_x
```

这是 Rodrigues 公式的局部展开。

### D4. SO(3) 对数映射

对数映射把旋转矩阵变回旋转向量。常见关系是：

```text
theta = arccos((trace(R)-1)/2)
```

再从反对称部分恢复轴方向。  
接近 `0` 或 `pi` 时要做特殊处理，因为数值上容易不稳定，且在 `pi` 附近表示不唯一。

### D5. se(3) 与 twist

常见写法是：

```text
xi = [omega, v]

hat(xi) = [ [omega]_x  v ]
          [    0       0 ]
```

其中 `omega` 表示角速度部分，`v` 表示线速度部分。  
不同教材可能先写 `v` 再写 `omega`，只要约定一致即可。

### D6. SE(3) 的 Exp / Log

`Exp` 把李代数中的局部增量映射到刚体变换，`Log` 把刚体变换拉回局部切空间。  
它们适合：

- 位姿插值
- 优化迭代
- 误差定义

更完整地说，SE(3) 的指数映射里平移部分会出现一个与旋转相关的矩阵 `V`：

```text
T = [ R  Vv ]
    [ 0   1 ]
```

### D7. 位姿误差

常见有左误差和右误差两种写法。比如左误差可写成：

```text
T_err = T_target^{-1} T_estimated
e = Log(T_err)
```

误差向量落在参考位姿对应的切空间里。  
关键不是“哪种唯一正确”，而是全程保持同一套约定。

### D8. 常见误区

逐条修正如下：

1. 错，旋转向量不是欧拉角。
2. 错，任意 `3x3` 矩阵不一定是旋转矩阵。
3. 错，四元数只有 4 个分量，但自由度是 3。
4. 错，位姿变换不能像普通向量那样直接相加。
5. 错，`Log(Exp(x))` 只有在局部和主值范围内才可看成近似/等价。

## E. NumPy 代码训练题

### E1. SO(3) 基础工具

参考实现要点：

- `skew(vector)`：返回 3x3 反对称矩阵
- `project_to_so3(matrix)`：对输入做 SVD，取 `U @ Vt`，若 `det < 0` 则修正符号
- `is_rotation_matrix(matrix)`：检查形状、有限性、正交性和行列式

核心验证标准：

```text
R^T R ≈ I
det(R) ≈ 1
R^{-1} ≈ R^T
```

### E2. 旋转表示转换

实现时要明确四元数顺序，比如统一用 `[w, x, y, z]`。  
参考要点：

- 轴角转矩阵：单位轴先归一化，再用 Rodrigues 公式
- 矩阵转轴角：先算 `trace`，再根据反对称项恢复轴；接近 `0` 和 `pi` 时分支处理
- 四元数转矩阵：按固定顺序展开
- 矩阵转四元数：按 `trace` 或主对角分量选分支，避免数值不稳定

### E3. SE(3) 变换库

函数应支持：

- 构造 4x4 齐次矩阵
- 求逆
- 对单点和批量点变换
- 复合两个变换

变换点时记得先补齐次坐标，再乘矩阵，最后去掉最后一维。

### E4. exp / log 数值实验

参考重点：

- `so3_exp` 用 Rodrigues 公式
- `so3_log` 用 `trace` 求角度，再用反对称部分恢复轴角
- 小角度用级数近似
- 接近 `pi` 时单独处理

验证时看三件事：

- `Exp(Log(R)) ≈ R`
- `Log(Exp(w))` 在主值范围内是否还原
- 误差是否在 `0`、中角度和 `pi` 附近明显变大

### E5. 可视化

图里至少要画出：

- 世界系
- 两个子坐标系
- 一个被变换的点

再用数值结果和图像结果互相核对，确保顺序没有写反。

### E6. Gimbal lock 数值观察

当 pitch 穿过 `90°` 附近时，欧拉角恢复结果通常会出现：

- yaw / roll 跳变
- pitch 仍连续但角度表达不稳定
- 对应旋转矩阵本身仍是连续的

这说明问题出在参数化，不在旋转本体。

## F. 应用与理解

### F1. 机器人坐标变换

一条常见链路是：

```text
T_world_target = T_world_base T_base_camera T_camera_target
```

每一段都必须先确认“谁到谁”，再决定乘法顺序。

### F2. 表示选择

1. 网络输出朝向：常用四元数或旋转矩阵
2. 配置文件里记录姿态：常用欧拉角，便于人读
3. 连续平滑插值：常用四元数
4. 优化器里的小步更新：常用李代数增量
5. TF 树传递完整刚体变换：常用齐次矩阵 / 四元数 + 平移

### F3. 调试清单

发现位姿错了时，优先检查：

- 坐标系命名
- 变换方向
- 乘法顺序
- 角度单位是度还是弧度
- 欧拉角顺序
- 四元数分量顺序
- 矩阵存储约定
- 时间戳是否对齐

### F4. 数值误差与验收

“误差达标”不能只看单次成功。  
更可靠的是记录：

- 多随机种子结果
- 最大误差
- 平均误差
- 边界样例
- 失败样例

这样才能判断实现是真的稳，还是只是碰巧过了一个样本。
