## A. 向量与矩阵基础
### A1. 向量是什么？
请用自己的话解释：向量可以表示哪些东西？在几何上和数据上分别怎么理解？

答：向量是一连串的数据，可以表示坐标、数组，在几何上通常可以表示点在指定坐标系中的坐标，在数据上就是一组数据，它们需要做相同的加减乘除计算，用向量来表示更为方便。



### A2. 矩阵是什么？
请分别从两个角度解释矩阵：

+ 作为一组数字表格
+ 作为一个线性变换

答：作为一组数据表格，矩阵是几行几列的数据组，通常是为了方便计算才写成矩阵形式；

作为一个线性变换，左乘或右乘一个矩阵可以表示坐标旋转，相位变化等，可以用来表示线性变化。

### A4. 线性相关与秩
请解释：

+ 什么是线性相关？
+ 什么是矩阵的秩？
+ 秩不足时，方程组 `Ax = b` 可能出现哪些情况？

答：线性相关就是一组向量中有一个可以由其他的向量线性表示。

## B. 最小二乘
### B1. 为什么需要最小二乘？
当方程组 `Ax = b` 没有精确解时，最小二乘想找到什么样的 `x`？

答：最小二乘找的是是的 ||Ax-b||最小的解，这个叫向量的二范数吧，还是模或长度，或者其他范数。由于欠定，没有唯一解，本质是找最接近方程的解的一组数据。



### B2. 最小二乘最小化的是什么？
请解释下面这个目标函数的含义：

```latex
min ||Ax - b||^2
```

答：找到使 Ax-b 的二范数最小的x



### B3. 直线拟合
假设你有一组二维点 `(x_i, y_i)`，想拟合直线：

```latex
y = ax + b
```

请写出如何把它整理成 `Ax = b` 的形式。这里的未知量是什么？

答：由于 y_i = a xi +b = [a b] [x_i, 1]T, 写成矩阵就是 [y_1 y_2 ... y_n]T= [a b] [x__1 x_2 ... x_n \n 1 1 ... 1]T，_这里的未知量是[a b]这个向量。

### B4. 法方程
普通最小二乘常见解法是：

```latex
x = (A^T A)^(-1) A^T b
```

请解释为什么这个公式在数值上可能不稳定。

答：因为需要求逆矩阵，而求逆矩阵的条件是矩阵满秩，而且跟矩阵条件数有关，条件数越小，越容易求逆，数值上越稳定。
